Short links like `plcc.org/camp` go on flyers and get read out on a Sunday. The address that
gets printed can’t change, but what it points to can: Church Center makes a new
registration page for camp every year, and the short link moves with it.

## Steps

1. In the editor (/admin), open **Short links** and choose **Add File**.
2. **Short link** is the address itself: `/camp` makes `plcc.org/camp`. The entry is named
   after it, so the list reads as the addresses people type.
3. **What kind of link:** leave it as **Shortcut** unless you’re sure (see below).
4. **Links to:** where it goes. A page on this site like `/visit/`, or a full `https://`
   address.
5. **Review by:** when to check it’s still right. For a sign-up, when the sign-up closes.
   For a page that has moved, about a year from now.
6. **Notes:** anything the next person should know, like which flyer it’s on.
7. **Save.**

**Live in:** a few minutes. Both `plcc.org/camp` and `plcc.org/camp/` work, so it doesn’t
matter which one gets printed.

## Shortcut or moved for good?

- **Shortcut** stays yours to re-point next year. Choose it whenever you’re unsure.
- **Old page that has moved for good** tells browsers to remember the destination more or
  less forever. They stop asking the site, so re-pointing it later won’t reach anyone who
  has already followed it. Use it only when an old address has genuinely moved for good.
- **Old page that is gone** tells browsers and search engines a page no longer exists.
  Leave **Links to** empty.

## Review dates

The date is a prompt, not a switch: **the link keeps working after it**. A flyer doesn’t
stop existing because a date passed. What the date buys is a list someone can actually
tidy, because without one nobody remembers what a link was for.

For something the church will simply always have, like the podcast, tick **Never needs
reviewing** and leave the date empty. Ticking it _and_ setting a date won’t save, because
the next person couldn’t tell which to believe.

## Re-pointing or retiring one

Open the entry, change **Links to** (and the review date), and save. To retire one, delete
the entry, but only once whatever printed it is gone.

## If something goes wrong

- **The site stopped updating after you added one.** A short link can’t have the same
  name as a page on the site: `/camp` is fine, but `/visit` would hide the Plan a Visit
  page. Rather than take the page down, the rebuild stops. Rename the short link.
- **The list is long.** It holds hundreds of entries and the editor has no search box, so
  scan the names; each entry is named after its address.
