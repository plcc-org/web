For a typo, an updated sentence, or a paragraph that needs rewriting.

## Steps

1. Open the editor (/admin) and choose **Pages**, then the page.
2. Find the words:
   - **On the page itself.** The page shows beside the form. Click the section you want and
     its block opens in the sidebar.
   - **In the form.** Under **Body**, each block is a bar labelled with its heading. Click the
     bar to open it.
   - **At the very top of the page** (the title, the intro line, the button) is **Top of
     page**, above Body.
3. Edit the words. Most blocks keep their paragraphs in a field called **Text**. As you type,
   the page beside the form updates.
4. Choose **Save**.

**Live in:** a few minutes, once the site has rebuilt.

## Inside a Text field

The **Text** field has a small toolbar: bold, italic, links, bulleted and numbered lists,
quotes and headings.

- **Headings.** The block’s own heading is set in its **Heading** field, so headings inside
  the text start one size down. Use them to break up a long block, not to start a new
  section; for that, add a new block.
- **Links.** Select the words, choose the link button, and paste the address:
  - a page on this site, starting with `/`, like `/visit/`
  - a website, as the full `https://` address
  - an email, as `mailto:` followed by the address, like `mailto:office@plcc.org`
  - a phone number, as `tel:` followed by the number, like `tel:+14253928636`

  Anything else turns into a dead link when it’s published.

- **Quotes and apostrophes.** Type curly ones (’ “ ”) in a Text field: a straight `'` stays
  straight on the page. On a Mac, Option-Shift-] makes ’, and Option-[ and Option-Shift-[
  make “ and ”. The shorter fields (an intro line, a card’s text) curl straight quotes for
  you.

## Before you save

Read it through against the [four questions in Editorial voice](./voice.md#before-you-publish).
The first one matters most: could this sentence describe any church?

## If something goes wrong

- **The change isn’t on the site yet.** Give it a few minutes; see
  [Something looks wrong](./something-looks-wrong.md#my-change-isnt-showing).
- **A link turned into `#`.** The address wasn’t one of the four kinds above.
