A few lists live in one place and show up wherever they’re used: change them once and every
page that shows them follows.

| In the editor          | What it is                          | Where it shows                                                 |
| ---------------------- | ----------------------------------- | -------------------------------------------------------------- |
| **Leadership**         | Pastors and staff                   | The leadership page                                            |
| **Youth moments**      | The youth year’s trips and retreats | Pages with a **Youth moments** block                           |
| **Homepage quotes**    | Things people have said about us    | Pages with a **Quotes carousel** block                         |
| **Photo descriptions** | One description per photo           | Everywhere the photo appears ([Add a photo](./add-a-photo.md)) |

Each is **one entry holding a list**. You open the entry, then work inside the list. For
the first three, the order of the list is the order on the page.

## Steps

1. In the editor (/admin), open the list (say **Leadership**). Its one entry opens
   straight away, with everything in the list below.
2. To **add** someone or something, use the **+** on the list. To **change** one, click it.
   To **reorder**, drag it by its handle. To **remove** one, use its bin icon.
3. **Save.**

**Live in:** a few minutes.

## What each one asks for

- **Leadership:** **Name**, **Role / title** as it reads under the name (“Lead Pastor”), a
  portrait-shaped photo, and a **Bio** of a few short paragraphs. The Bio has bold, italic
  and link buttons; use those rather than typing symbols. **Portrait description
  (optional)** can stay blank: their name and role are used. A **Read-more link** shows only
  when both its parts are filled in.
- **Youth moments:** **Title**, **When (optional)** as a date range or a season (“Each
  spring”), and a **Blurb**. **Featured** moments get a large card; the rest fall into a
  compact list.
- **Homepage quotes:** the **Quote**, and **Who said it (optional)**. A quote earns its
  place by saying something specific about Pine Lake; see [Editorial voice](./voice.md).

## If something goes wrong

- **There’s no Add File button.** That’s expected: there’s only ever one entry. Open it
  and add to the list inside.
