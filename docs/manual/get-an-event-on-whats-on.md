Events aren’t edited in the website’s editor. [What’s On](/events/) reads the church’s
calendar in **Planning Center** every night, so getting an event onto the site means getting
it right in Planning Center.

## What the site takes from Planning Center

- **Only public events.** An event appears only if it’s set to show in **Church Center**,
  the church’s public Planning Center site. Everything else on the calendar (staff meetings,
  room bookings, rehearsals) stays off the website. That’s the safety catch, so check it
  when an event is missing.
- **The next eight weeks.** Each night the site picks up public events from today through
  the next 56 days.
- **The published start time.** If the event reserves setup time before it starts, the
  site shows the time the public is told, not the start of the room booking.
- **The summary.** The event’s short summary is shown on its card. With no summary, the
  start of the longer description is used instead, cut short to fit, so a summary written
  for the card reads much better. The website’s [voice](./voice.md) applies here too: plain,
  specific, no exclamation marks.
- **Where it is.** Events on the church campus don’t repeat the address. Events elsewhere
  show the venue’s name.

## Steps

1. In Planning Center, create or edit the event and make sure it’s visible in Church Center.
2. Give it a short summary.
3. Tag it with the ministry it belongs to (see categories, below).
4. Wait for the next morning.

**Live:** the next morning. The site rebuilds itself at about 5am every day with the latest
calendar, which is also when past events drop off.

## Categories

What’s On sorts events into **Everyone**, **Families**, **Youth**, **Groups** and **Serve**,
and the **Featured events** block can show just one of them. The category comes from the
event’s Planning Center tags when they name a ministry, like Youth, Children & Families,
Congregational Care, or Missions / Service. Untagged events are sorted by the words in
their title, and anything that matches nothing goes under Everyone. Tags are the reliable
way: if an event lands in the wrong category, tag it.

## How the page is arranged

- **This week:** everything in the next seven days.
- **Coming up:** one-off events after that.
- **Regular rhythms:** every repeating event, listed once, by the day it happens. A weekly
  group appears here even in a week when it’s also in “This week”.

## If something goes wrong

- **The event is missing.** Is it visible in Church Center? Is it within eight weeks? Has a
  night passed since it was added?
- **It shows an hour early.** Check its published start time in Planning Center.
- **Nothing on the page has changed for days.** The nightly update may have stopped. Tell
  whoever looks after the site’s code.
