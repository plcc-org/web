Photos carry this site. They answer the question a newcomer is really asking, “would I be
out of place here?”, faster than any sentence can. So choosing one is worth a minute.

## Choosing the photo

- **Portrait, not landscape.** The layouts are built around tall photos. A wide one gets
  its edges cut off.
- **People over places.** An empty room says nothing. Faces say who’s here.
- **Candid over posed.** Nobody lined up looking at the camera.
- **Real, never stock.**
- **Look at the whole frame.** Check the background and the edges: the crop may land
  where you don’t expect, and the thing you didn’t notice is the thing everyone sees.
- **Once per page.** Don’t use the same photo twice on one page. Across pages is fine.

## Steps

1. Open the block’s **Photo** field and choose a photo from the library (it shows the
   first few dozen; scroll down for more), or upload a new one. Uploads must be **JPEG, PNG, WebP or AVIF**. A photo straight off an iPhone is
   usually **HEIC**: export it as JPEG first (in Photos, File → Export).
2. **Describe it, once.** Every photo needs a description for people who can’t see it.
   - If the photo is already in **Photo descriptions**, leave
     **Different description for this page** blank. The saved one is used.
   - If it’s new, the block shows “This photo has no saved description yet”. Write the
     description right there, **before you leave the block**: the editor only checks while
     the block is open, and a page saved with an undescribed photo stops the site updating.
     If the photo will be used again, also add it under **Photo descriptions** in the
     sidebar, so every page that uses it gets the same one.
3. **Save.**

**Live in:** a few minutes. A photo you’ve just uploaded shows blank in the editor’s preview
until then. It’s saved, and it will appear.

## Writing the description

Write what someone who can’t see the photo needs in order to follow the page.

- ✅ “A volunteer making coffee at the welcome café before the service”
- ❌ “coffee”
- ❌ “photo of church”

If people are doing something, say what they’re doing. Only fill in **Different description
for this page** when this page needs different words, for example because the
paragraph beside it is about something else in the frame.

## If something goes wrong

- **The upload is refused.** It’s probably HEIC or another format; export it as JPEG.
- **The form says the photo has no saved description.** Describe it there, or add it to
  Photo descriptions. If you’ve only just added it there, the form may not know yet: write
  it on the page too, just this once.
- **The photo is blank in the preview.** Normal for a new upload until the site rebuilds.
